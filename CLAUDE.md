# Poster Studio

Laravel 13 + Vue 3 SPA (vue-router, served by Laravel) + Tailwind 4. Subscription service that makes Instagram/Facebook posters and reels (customer picks the reel length 15/30/45/60 s, priced per length; clips must add up to it ± 3 s). Requirements: `docs/SRS.md`.

- Flow: `POST /api/v1/creations` → `RunCreation` job → `CreativeAgent` (Claude Fable + tools) → posters cropped by `PosterFormatter` / reel assembled by `ReelAssembler` (ffmpeg) → `outputs`.
- Fable picks the image (GPT Image, Gemini, Gemini Pro) and video (Seedance, Veo) provider per call; Gemini/Veo run through the Gemini API or Google Cloud Vertex AI (`GEMINI_VIA`/`VEO_VIA=vertex`, auth in `App\Services\AI\Vertex`: service-account JSON, or an API key for images only); video providers declare their clip lengths in `durations()`. Never expose provider/model names to customers: customer responses go through `CreationResource`; internals (`assets`, `steps`, `summary`, `error_detail`) only via `AdminCreationResource`. A feature test checks for leaks.
- Nothing is overlaid by code; the generated image is the deliverable. The client's logo is never given to a model (they redraw it): `LogoOverlay` (`add_logo` tool) places the original file pixel-exact, scaled evenly; `CreativeAgent` refuses the logo as a reference. Image models never write words (they misspell Mongolian): the poster's message (headline, offer, price, date, place, CTA) is set on a text-free visual, and in reels on the clips, by `TextOverlay` (ffmpeg drawtext, `add_text` tool) with the OFL fonts in `resources/fonts` (keep their OFL licence files; Playfair has no ₮ glyph — strings with ₮ fall back to Montserrat).
- Fable API rules: no `thinking` param, no forced `tool_choice`, effort via `output_config`, `fallbacks: "default"` with the `server-side-fallback-2026-07-01` beta header. Pass assistant content (incl. thinking blocks) back unchanged.
- Skills: bundled in `resources/ai/skills/<name>/SKILL.md` (frontmatter `name`, `description`, optional `origin`), custom ones in the `skills` table (admin, can import a Claude `SKILL.md`). `SkillLibrary` builds the index and serves `load_skill`. `php artisan skills:export [--install]` writes them as Claude Agent Skills (`studio-` prefix; zips for claude.ai in `storage/app/claude-skills`, `--install` copies to `~/.claude/skills`). Several bundled skills are adapted from Claude skills; keep their `origin` line and LICENSE files (Apache-2.0 for theme-factory/canvas-design; MIT for the 8 skills from coreyhaines31/marketingskills, kept unchanged with their `references/` — `load_skill` takes `reference` to read one, and `skills:export` skips them since the originals are installed in Claude Code directly). Recommended skill sets per job type are listed in `resources/ai/creative-director.md`.
- Billing: QPay v2 (`QPayClient`); never trust callback payloads, always verify with `payment/check`. `BillingService::markPaid` is idempotent and extends from the current end date. `QPAY_FAKE=true` for local only.
- API is under `/api/v1` with the session guard + CSRF (`X-XSRF-TOKEN` from cookie). Middleware alias: `admin`. Billing is credit-based (`config/pricing.php`, `docs/PRICING.md`): `Credits` charges the job price when it starts (402 if short) and refunds failed jobs; credits live on subscription rows (free tier = one never-expiring grant from the plan priced 0). Each job has a USD media budget enforced in `CreativeAgent`; `CostMeter` derives credit prices and media budgets from the unit costs + `pricing.estimates` (≥2× worst, ≥3× typical) and records real cost (`cost_usd`); see `php artisan pricing:report` / admin Өртөг page.
- Tests: `php artisan test` (all external HTTP faked with `Http::fake`). Build: `npm run build`. UI copy is Mongolian.
